Skill Tree & Allocations

Blood Wave Necromancer Skill Tree with Point Requirements

Skill Allocation Strategy

  • Start by maxing out core damage skills (Blood Wave tree)
  • Then invest in survivability (Bone skills for Iron Maiden, Reap)
  • Then mobility and utility (Sever, Blood Mist)
  • Finally, optimize enhancement nodes for maximum damage

Core Blood Skills (PRIORITY)

Skill Type Points Needed Description
Blood Wave Core Skill 5 pts Your main damage - max this first
Blood Surge Blood Skill 3 pts Enhancement for blood skills
Hemorrhage Blood Skill 3 pts Critical chance increase
Blood Mist Blood Skill 3 pts Corpse consumer + teleport
Blood Lance Blood Skill 3 pts OP stack consumer

Bone Skills (SUPPORT & SURVIVABILITY)

Skill Type Points Needed Description
Reap Bone Skill 5 pts Resource recovery - essential
Iron Maiden Bone Skill 5 pts Automated by Teb rune
Bone Prison Bone Skill 5 pts Attack speed boost
Bone Armor Bone Skill 3 pts Survivability layer
Decompose Bone Skill 1 pt Corpse gen option

Reaper Skills (MOBILITY)

Skill Type Points Needed Description
Sever Reaper Skill 5 pts Teleport + corpse gen - essential
Serration Reaper Skill 3 pts Enhanced mobility

Enhancement Nodes

Node Type Points Needed Priority
+20% Critical Strike Damage Passive 3 pts HIGH
+15% Attack Speed Passive 2 pts HIGH
+10% Damage vs Elites Passive 2 pts MEDIUM
+10% Maximum Life Passive 3 pts HIGH

Allocation Order

  • Step 1: Max Blood Wave (5 pts)
  • Step 2: Max Reap (5 pts) + Iron Maiden (5 pts)
  • Step 3: Max Sever (5 pts) + Blood Mist (3 pts)
  • Step 4: Add blood skill enhancements (Hemorrhage, etc.)
  • Step 5: Fill in critical damage and attack speed nodes
  • Step 6: Add survivability (Bone Armor, max life nodes)

Board Progression Visualization

  • STARTER: Dominate → Build damage foundation
  • → MIDGAME: Essence (level glyph to 50) → Add survivability
  • → ENDGAME: Gravekeeper + Imbiber → Unlock specialty synergies
  • → PUSH: Corporeal → Final optimization

Glyph Priority

  • HIGHEST: Essence to 50 (unlock board)
  • HIGH: Dominate (direct damage multiplier)
  • HIGH: Bloodbath (part of core rotation)
  • MEDIUM: Gravekeeper (corpse synergy)
  • MEDIUM: Imbiber (blood skill synergy)
