# Blood Wave Necromancer - Gear Progression Guide

Interactive Diablo IV Season 15 gear progression guide for Blood Wave Necromancer builds.

## View the Guide

📖 **[Open Interactive Guide](https://morganjp94-sudo.github.io/Diablo/)**

## Features

- ✅ Four progression stages (Starter → Midgame → Endgame → Push)
- ✅ Detailed equipment recommendations
- ✅ Stat priority lists for each piece
- ✅ Target stats for each progression phase
- ✅ Tips and optimization strategies

## Stages

1. **Starter** (Torment 1-4) - Focus on survival and resource management
2. **Midgame** (Torment 5-8) - Balanced offense and defense
3. **Endgame** (Torment 9-12) - Optimization with perfect rolls
4. **Push** (Torment 13+) - Maximum perfection for leaderboards
